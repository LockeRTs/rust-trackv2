# Rust Track — Server Browser Edition

## Обновления
- Исправлена проверка SteamID64 при сохранении профилей: валидный 17-значный SteamID64 больше не отклоняется из-за ошибочного регулярного выражения.
- Фон и оформление вдохновлены браузером серверов Rust: тёмная оливково-графитовая палитра, текстурный фон, полупрозрачные панели и компактная навигация.
- Добавлен пункт «Разработчики» в левое меню.
- Страница разработчиков содержит Miurexz, Locker и Wate.
- Сохранены список наблюдения игроков и красные акценты.
- Подпись исправлена на «ОЧИВКА» через О.

## Запуск
1. Установи Python 3.11+.
2. `pip install -r requirements.txt`
3. Задай `STEAM_API_KEY`.
4. Для администратора задай `ADMIN_USERNAME` и `ADMIN_PASSWORD`.
5. `python app.py`

Для production настрой `SECRET_KEY`, `DATABASE_URL` и `COOKIE_SECURE=true` при HTTPS.

Важно: Steam-профили и игровая статистика должны быть открыты, чтобы Steam API мог вернуть данные.
